# Gait AI website

Public website for the Gait AI Ortho-Team project.

Live site: https://adambahelka.github.io/gait-ai-website/

## Edit the website

Edit `docs/index.html` for page content and `docs/styles.css` for styling. Images live in `docs/assets/`. Open `docs/index.html` in a browser for a local preview.

GitHub Pages publishes the `docs/` folder from `main`. Changes pushed to that folder are deployed automatically. No build or dependency installation is needed.

The homepage walking image is an AI-generated illustration. The page links to the published research and its correspondence details.
